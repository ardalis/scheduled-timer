    Configuration

    How long your talk is; the timer counts down from this. Any number of minutes, e.g. 20 or 7.5.

    The new duration applies when the current timer is reset.

    Off by default, so a presentation remote sending keys to this window can't change the timer.

    Theme

    A theme is a named set of styles. Choosing one replaces the styles below.

    Styles

    Each style starts at a number of minutes from zero: positive before, negative over time. The closest to zero applies.
